# Yeva Soroka · Portfolio (version 3)

Version 3: the look of version 1 (`../portfolio-site`) on the grid from the Figma file
"my-website" (Frame 9, Slides 2–4): 30px margins, header 30px from the top,
titles 30px under the header, one screen per section, Figma font sizes.

Version 2 is in `../portfolio-site-v2`.

Open `index.html` in a browser (or run `python3 -m http.server` in this folder).
Russian version: `index.html?lang=ru`.

## Fonts
The fonts (Unbounded and Manrope, Latin and Cyrillic) are stored in the `fonts` folder and loaded from there,
nothing comes from Google. When you upload the site, upload the `fonts` folder together with `img`.
